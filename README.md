# Weekly Task & Habit Tracker

## Project Description

The Weekly Task & Habit Tracker is a Python-based program designed to help users organize their weekly tasks and monitor their daily habits.

The program allows users to add, complete, and remove tasks and habits. It also provides daily and weekly reports to help users track their progress.

## Features

Add tasks for different days of the week.

Add habits to track throughout the week.

Mark tasks and habits as completed.

Remove tasks and habits.

View daily reports.

View weekly reports showing completed and incomplete tasks and habit progress.

## How to Use the Tracker

1. Run the Program

Open a terminal, navigate to the project directory, and run the Python file:

python T_Rahimi.py

2. Main Menu

After running the program, a menu will appear with the following options:

Add Task/Habit

Mark Task/Habit Complete

Remove Task/Habit

View Weekly/Daily Reports

Exit

Enter the number corresponding to the action you want to perform.

3. Add Tasks and Habits

Choose option 1 to add a new task or habit.

For a task, enter the task name and select the day of the week.

For a habit, enter the habit name.

4. Mark Tasks and Habits as Complete

Choose option 2 to mark a task or habit as completed.

5. Remove Tasks and Habits

Choose option 3 to remove a task or habit you no longer want to track.

6. View Reports

Choose option 4 to view your progress.

Daily reports show the tasks and habits for a selected day.

Weekly reports summarize completed and incomplete tasks and show habit progress throughout the week.

7. Exit

Choose option 5 to exit the program.
